# 已有 HTML 转为三栏工作台

只在用户给已有 HTML／路径并要求转换时使用。已有工作台走原文件迭代，不重新初始化。

## 先识别与保留

读取源 HTML 的页面、状态、事件、样式、资源、缓存及现有说明。走通本次需保留的输入、按钮、列表、跳转、弹窗和返回路径，记录原行为。转换默认另存工作 HTML，保留源文件；业务数据、页面设计、原有说明与交互是主体，不用模板示例、截图或简化重写替换。

明确产品、端、页面与需求归属，使用用户提供或已有配置中的名称；缺失且不阻碍转换时标未标明。左侧默认按「产品 → 端 → 页面」分组，保留产品级全局说明，不新增端级正文。同产品不因跨端或需求重复建产品组；跨端及跨产品同名页面均保留各自稳定 ID、页面状态和说明归属，已有端标签不擅自改名。目录组织见 [工作台约定](workbench-contract.md)，代码映射见 [模板接入](template-map.md)。

读取代码是为了保留行为，不等于授权把所有代码行为写成研发说明。明确要求写入的文字直接落位，缺项留空；原有正文、说明和用户草稿保留。

## 接入选择

优先将业务作为独立适配器接入通用外壳：配置 requirements/pages/navigation，迁入原数据与逐页 views，完成 render、bind、scene、root、context、reveal 及必要校验。渲染和验证不能执行业务提交。原事件需要共享业务状态时保留共享关系；不同产品不误用同一份数据。

保留原 DOM 更合适时可以接入原结构，不强制重写业务。说明保存／编辑只更新右栏和标注层，不能为保存一句话重建业务 DOM。表单输入、未提交弹窗、选择器展开、页面与列表滚动都要能保存并恢复。状态不能只留在闭包变量或浏览器缓存，导出必须带走。

iframe 可隔离原 CSS、设计视口与脚本，但不是自动完成转换：可访问的业务根要接通事件、元素描述、跨根路径、场景恢复、保存及导出。Shadow DOM 同样逐根接入。无法访问的外部 iframe 先内联可用内容或明确具体限制，不能把能选中宿主说成能标注内部。普通单文件原型不为隔离强加复杂框架。

## 完整 HTML 与资源

内联必要 CSS、JS、图标、字体和图片，不依赖源目录、CDN、后端或构建工具才能打开。相对路径资源、模块导入、fetch 和 localStorage 要逐项处理；保留原交互，不把网络错误当成“离线也可用”。已有真实接口与授权副作用的范围单独说明，验证用隔离数据，不擅自提交真实业务。

中间设备画布使用实际设计尺寸；业务响应式依据画布宽度，外壳三栏按浏览器窗口响应。中间外层填满空间，只缩放内部业务与标注，保留原内部滚动。不要只固定外壳宽度，却让业务 @media 继续随宿主窄屏挤压手机。

## 标注与导出

原手工锚点和编号保留；未预设锚点的可见元素也能选。动态行补稳定记录 ID，不能用行号替代身份。弹窗、折叠和下一层的说明应能从真实入口数量标识发现；定位时只恢复必要场景，不覆盖当前可见表单。详见 [元素选择](element-targeting.md)。

导出使用原始外壳加当前完整模型，不能直接保存运行后 DOM。可编辑副本保留草稿，readonly 标记同时约束 UI 和写入入口；只读文件保留目录、业务交互、比例和定位。JSON 内嵌转义 <、>、&，正文按纯文字显示。默认不触发任何下载。

## 迭代兼容与验收

原工作文件先备份，保留 artifactId、snapshotId、页面／记录／说明 ID 和编号计数。缓存冲突按 [存储约定](storage.md) 处理；不能通过清空浏览器或换身份回避，也不批量升级其他用户原型。

对实际转换文件运行 [通用产物验证](verification.md)，补原业务的定向场景。新旧原型对照主要流程、数据和输入保留；真实浏览器检查布局、跨根选择、缩放后的命中与滚动、标号联动及实际只读边界。脚本未覆盖的路径明确记录。交付转换后的可编辑工作文件，说明源文件、变化页面、保留行为与具体局限。
