# 任意可见元素的选择与定位

用于新建模板和已有 HTML 转换。选择范围是中间业务原型的可见 DOM：文字所在元素、图片、图标、按钮、链接、表单、禁用控件、表格单元格、容器及弹窗子元素。用户不必先请求 Codex 给某个区域加锚点；正文仍是唯一填写项。

## 拾取与业务事件

`selectableElement` 判断元素是否属于当前可见业务根，排除脚本、样式、隐藏场景和工作台自己的角标覆盖层。`activeRoot` 必须跟随业务状态变化，例如打开弹窗后指向弹窗内部。动态渲染后仍通过事件委托获取实际目标，不只给初始化时的节点注册监听。

工作文件在「查看原型」时就提供小型「选位置写说明」按钮，不提供独立写说明模式。每次点按钮才捕获一次目标，成功后立即关闭拾取，右侧出现单一正文输入；后续点击恢复业务，要选下一个元素需再点按钮。工作文件始终保留原业务操作，说明保存不重建业务 DOM。模板在 `pointerdown` 阶段选择实际元素并阻断业务处理，同时抑制这一手势后续的 `pointerup` 和 `click`，避免选中按钮就打开、提交或导航。禁用控件可能不派发 `click`，仍通过指针事件选择。程序化点击和键盘也走同一选择入口。不能靠给所有控件设 `pointer-events: none` 实现拾取，否则命中的是外层而非真正的控件。

源 HTML 的装饰图标或文字可能设置了 `pointer-events: none`。仅在拾取时让业务根内的这些可见元素参与命中，结束后恢复原规则；不要启用工作台覆盖层的整块指针事件，也不取消背景场景的 `inert`。真实浏览器检查这种图标能选中自身，不能仅用合成事件代替命中测试。

悬停显示实际选择范围和位置，↑ 转到外层容器、↓ 返回内层，Enter 确认，Esc 取消。模板临时让可见元素可聚焦，取消或选择后精确恢复原 `tabindex`；不覆盖原角色、ARIA 标签或业务属性。原编号及框线仍可用于定位已有说明，不能成为新说明的目标。

## 稳定位置

已有手工锚点保留原 ID。未预设锚点时，`selectionRecord` 将位置描述编码为 `element:` 开头的 `anchor` 字符串，和正文、页面、场景、上下文一起保存在原说明模型中；不另增需要用户填写的字段。`findAnchor` 同时解析旧锚点和自动位置。

自动描述由唯一稳定基点、基点内的元素路径、目标校验信息组成。基点优先使用 `data-anchor`、`id`、`data-record-id`、`data-row-id`、`data-key`、`data-id`；目标的标签与静态属性、直接文本用于校验，输入值和样式不作为身份。表格行没有自己的键时，模板可通过其内部已有稳定锚点找到所属行，再定位单元格。

转换重复列表或卡片时，给每条记录的容器保留或补上业务 ID。仅用第几行、全页 `nth-child`、当前文案或随机运行时属性，会在插入、排序、重绘后误指其他记录；不能当作稳定位置。路径只在已确认的稳定基点内使用，校验不通过时显示位置失效并允许重新定位，不猜测相似元素。

同样给动态选项保留稳定键。模板中的评论卡片以 `data-record-id` 绑定记录，分类内的标签选项以「分类与标签」组合键绑定；切换分类后不能把第一个复选框的说明套到新分类的第一个选项。静态选项可定位到选择器本身；操作系统绘制的原生下拉菜单不当作独立业务 DOM。

## 状态恢复与验证

目标已经可见时直接联动高亮，保留输入；否则沿用原场景恢复机制，再解析自动位置。弹窗内部说明继续归入打开它的按钮旁的数量标识。只读导出带上位置描述和场景，保留定位、取消写入入口，不主动下载只读预览。

`elementAnchorKnown` 必须验证真实位置。模板的业务渲染器仅返回 HTML，因此可以在隔离的视图副本中生成离线 DOM，查找目标后恢复原视图引用；不触发业务 click、不提交表单、不改原数据、不渲染到用户页面。已有 HTML 的渲染器若有副作用，改用该业务的纯快照／稳定键验证接口，不能照搬调用。失效目标需保留提示，并在导出前按既有规则要求修复或删除说明。

若源页面包含 iframe 或 Shadow DOM，分别接入可访问业务根的事件和位置解析，记录根的稳定路径；不要把事件被重定向到宿主就当作内部元素可选。不能访问的外部 iframe 应先内联可用原型内容或明确具体限制；Canvas 位图内部不是独立 HTML 元素，Canvas 元素本身可以标注。

运行 `scripts/verify_elements.cjs`，默认在内存中捕获导出结果，不落地或下载预览。真实浏览器补查禁用控件、悬停范围、父子选择、选择时无业务副作用、普通操作恢复、选中后右侧联动，以及实际尺寸变化。测试说明只进入隔离副本，不能写进用户工作文件。
