# 工作台交互与交付约定

新建、迭代和转换都遵守这些已确认的行为。技术接入见 [模板地图](template-map.md)，正文来源见 [PRD 文字约定](prd-template.md)。下文的“默认空白”指缺失内容；用户已提供并要求写入的内容直接落位，已有正文与说明保留。


- **页面信息**：标题和目录展示页面名称、归属及功能信息，不添加「本轮新增／更新／修改／保留」等迭代状态标签；修改旧原型时也移除这类工具层标签。
- **首项全局描述**：左侧「需求说明」分组内的第一个菜单为「全局描述」，后面是「上线后数据需求」和「埋点说明」。点击后在中间打开独立正文页，工作文件直接显示一个多行输入框，输入即备份，从编辑入口填写后自动写入文件，不必切换模式或再次点击编辑。默认留空，不绑定产品、端或页面，不占业务页数和说明编号。只读导出中显示完整、可复制的纯文本并保留换行。切回业务页恢复原输入、弹窗、说明草稿和滚动位置；右侧仅展示适用范围。沿用 `model.globalContent` 和独立工具视图，不新增同名菜单、不改业务页面 ID。此正文独立于各产品的全局说明，不自动合并、替换或代写。
- **左侧两级目录**：「需求说明」及其三个文字入口之后，再按产品为一级分组、各页面为二级菜单。每个产品的第一个二级菜单固定为「本产品全局说明」，后面直接列业务页面，全部位于左侧；中间不再增加菜单或页面 Tab。页面下方标明 CMS、前台等端名及所属需求，同产品跨需求、跨端不重复建立产品组，同名页面凭完整归属区分。不为凑数量编造产品、端或页面。切换保留筛选、表单、说明草稿与滚动位置。
- **当前页面归属**：中间上方显示清楚的产品名、端名、需求与页面，常规高度的标题区随原型滚动保持可见；全局正文很长时随列滚动，避免遮挡后续内容；右侧标题下同步显示相同归属，只列当前页面的说明。名称必须直接可读，不能只靠颜色、图标或鼠标悬停；产品标识不占用说明编号的配色。没有用户提供的端信息时不根据“首页”猜测 App/H5/Web；按下方结构指南处理。
- **每个产品都有全局说明菜单**：点击左侧产品下面的「本产品全局说明」，中间打开独立正文页。默认一个大输入框，直接填写、自动写入已绑定的工作 HTML、随正文完整增高；以稳定产品 ID 独立保存，适用于该产品所有端与页面，其他产品和整个工作台的正文互不影响。缺失内容空白，不复制或擅自代写。全局说明是工具文档，不计业务页数、不占说明编号，不混入业务的弹窗、空结果等状态。只读导出保留相同的左侧菜单，正文完整、可复制。
- **中间顶部紧凑排列**：产品、端和标题放左侧，需求路径放右侧。业务页的状态切换放左侧，定位说明、小型「选位置写说明」按钮及重置工具放右侧；页面导航只在左侧。顶部和右侧不再常驻全局文字输入框，正文放进左侧对应的全局菜单。窄屏自然换行，不裁掉名称或遮挡按钮。
- **旧全局文字兼容**：旧 `globalNotes.prototype` 和 `globalNotes.notes` 属于整个工作台，非空时分别放到左侧「全局描述」页的原正文下方，按原归属标明并独立编辑；不自动并入主正文或复制到每个菜单。旧 `globalNotes.directory` 继续保存在模型和导出中，不再渲染目录框。旧缓存缺菜单正文时补空，不重置数据、说明或缓存身份。 上版 `menuGlobalContent` 中已经填写的内容，按原需求与端归属分块保留在所属产品的全局说明页下方，仍可编辑与导出；不要自动并入产品共用正文或删除。旧 `workspaceView: menu` 恢复为所属产品的全局说明视图。
- **中间交互原型**：承载业务操作、页面状态和编号定位。按用户提供的需求实现交互，转换时保留原有状态，不自行扩充业务规则；移动端产品的设备画布也放在此区。左侧导航和顶部工作工具不属于业务原型。
- **预览区底部**：不添加导出交付提示或「对照右侧同编号说明」图例；工作页和只读导出一致。移除对应容器及占位空间，让中间预览使用腾出的高度。
- **工作台整体自适应**：整个外壳占满窗口剩余宽高，各栏独立滚动，原型留在首屏，不把目录、原型、说明上下堆成长页面。≥1280px 默认保留左右等宽的三栏；900–1279px 默认收起目录、保留右侧说明；<900px 默认收起两侧，通过顶部「目录」「说明」展开互斥侧栏。两侧均可手动开关，窄屏的保存、导出和边框开关收进「更多」。侧栏可通过关闭按钮、遮罩或 Escape 收起，支持键盘操作；切换目录项后自动收起目录。调整窗口和收放侧栏只改变工具布局，不重建业务 DOM、不清空输入、弹窗或说明草稿。
- **侧栏与标注联动**：选中元素后自动展开说明编辑区；重新定位时先收起覆盖原型的侧栏。小屏点击说明的编号／正文定位时收起说明侧栏，再显示和高亮目标；点击原型编号或框线时展开并高亮对应说明。目标已显示时不能因工具层遮罩／inert 而重置业务场景。业务区域的普通点击继续原交互及被动高亮，不主动弹出侧栏抢焦点。工作页与只读文件共用布局，只有工作页可填写。
- **自适应预览与画布尺寸**：中间预览区铺满中间栏可用宽高，随窗口变化调整，不能用固定最大宽度或 `70vh` 留出大片空白。默认「自适应」，按可用宽高等比缩放原型，大屏可以放大超过 100%，小屏等比缩小；保持设计比例和完整内容，不能为了同时填满宽高而拉伸手机或裁掉按钮。手机画布左右的比例留白可以保留，外层预览容器仍须铺满。设计尺寸从用户稿件或原 HTML 获取；390 × 844 只是 H5 示例，不强加给其他产品。桌面左右栏等宽，窄屏按上述规则收起工具侧栏；业务布局按自身设计宽度响应。接入和实测要求见 [布局适配](template-map.md#布局适配)。
- **展示比例**：中间工具条保留 100%、90%、80%、70%、60%、50%、自适应。默认自适应；100% 显示原设计尺寸，其余百分比使用固定比例，空间不足由外层横纵滚动，四边和底部操作均可到达。只有自适应随可用宽高自动重算，充分利用空间且不限制为最多 100%。外层预览区始终铺满中间栏可用宽高，选择任何比例都不能使外层预览区跟着内容缩小。只缩放内部业务 HTML 及其标注；左侧目录、工具与右侧正文保持原大小，原型内部列表保持自己的滚动。切换比例不得重建业务 DOM、清空输入和说明草稿或切换场景；标注与画布同步缩放一次。按页面记住选择，切页、全局正文往返及导出后恢复；旧文件未存比例时采用自适应，已明确保存的 100% / 90% / 80% / 70% / 60% / 50% / 自适应继续尊重，不重置缓存；旧 98%、87%、76%、75%、65% 分别衔接为 100%、90%、80%、80%、70%，其他数据不变。只读文件也能调整查看比例，依旧不能写说明。
- **右侧文字说明**：保持原来的研发说明区样式和编号列表，全部展开，显示编号、正文、位置；点击页面标号或对应说明的编号／正文区域，原型位置和说明同时高亮并滚动到可见处。保留中间「定位说明」入口。点击只做定位，不展开、修改或执行业务；说明条目不增加折叠、页签、处理状态或类型筛选；窄屏可整体收起说明侧栏。 全局描述及需求正文页仍保留右侧「研发说明」标题，用简短范围文字提示，不改为另一套导航、Tab 或编辑面板。
- **说明文案**：需求范围和右侧说明直接描述最终的功能、展示规则、触发条件、交互行为与结果，不写「本轮」「本次」「这次新增」「按截图调整」「沿用旧版」「由原来改为」等过程、对话或变更经过。用户要求整理已有说明时，改写为最终规则，保留已确认的规则、必要的演示标识与功能边界，不补写业务规则。业务动作里的「新增记录」「更新数据」不属于过程性文案，不误删。
- **彩色标注框**：默认为当前可见的已标注区域显示边框；每条说明用稳定编号分配不同颜色，中间边框、数字角标与右侧编号同色，切页、编辑、导出不换色。右上角提供「显示标注框」开关，关闭时先隐藏全部边框，保留彩色编号和完整说明。点击中间编号、右侧编号／正文或定位菜单时，只显示并高亮当前说明对应的框；换一个编号就替换该框，其他框继续隐藏，开关仍保持关闭。再次关闭全局开关时清除临时显示的框。工作页与只读导出行为一致；每次打开文件默认显示全部可见边框。
- **点击框也联动**：未开启选位置时，点击彩色框线或框内区域，区域和右侧同编号说明一起高亮，右侧说明滚动到可见处。框线点击不触发底下业务按钮；框内输入、选择和按钮点击在高亮的同时继续原业务操作，不重建业务 DOM、不抢焦点、不滚动中间区域。嵌套时匹配最近的已标注区域。关闭全局边框后，隐藏的框不留透明热区，框内被动联动关闭；通过编号临时显示的框线仍可定位。选位置期间点击业务区域用于新标注，已有框线和角标可定位已保存说明。
- **定位不改业务状态**：按实际可见性判断，不能仅凭 DOM 存在或场景相同。目标可见时仅高亮和滚动，保留筛选、输入、弹窗和草稿；目标在已打开表单的折叠区或选择器里时，只展开该区域，保留当前输入。目标未显示时，恢复必要场景再定位；未保存的说明草稿不得静默丢失。标号和框线点击要拦截冒泡，不能触发底下的按钮；角标支持键盘 Enter／空格。右侧正文保持可选择复制。
- **只保留查看原型**：取消独立「写说明」模式及模式切换。工作文件一直可以体验原型，中间顶部的小型「选位置写说明」按钮每次只开启一次拾取，选中目标后立即关闭，右侧出现一个文本框和取消/保存。下一次普通点击继续业务操作；选择另一个元素需再次点按钮，未保存草稿先保存/取消。再次点击按钮或 Esc 可取消拾取，Esc 不关闭业务弹窗。已有说明的编辑、删除和重新定位入口直接位于原条目旁，无需切模式；原型区域只在拾取手势中拦截业务事件。只读导出移除所有填写和管理入口。
- **已有说明原位编辑**：点击某条说明的「编辑」，直接把该条原正文替换成输入框，在同一条内保存或取消；保留编号、颜色、绑定位置和列表顺序。不要弹窗、顶部另开编辑区或把右侧滚到顶端。编辑、保存和取消只更新说明区，不重建中间业务 DOM；输入框不能放在整块可点击定位区域内部，避免打字、换行或空格触发定位。草稿继续按页面暂存，切回后在原说明处恢复；新增说明从选位置开始，已有说明直接点击原条目的编辑。新增和编辑保存都不重建中间业务 DOM；只读导出不提供任何说明写入入口。
- **正文完整展开**：新说明和原位编辑的输入框默认约 8 行、高度至少 200px；全局描述框也要有足够的初始填写空间。输入、粘贴、恢复草稿和改变宽度后，根据内容自动增高，删除文字时可缩回默认高度。不用固定最大高度、输入框内部滚动条、折叠或省略号藏住正文；长内容通过所在列滚动阅读，保存后的文字和只读导出同样完整显示。只调整工作台文字编辑器，不改变业务原型自身的输入框行为。
- **所有可见元素可选**：中间业务原型中的文字、标题、图片、图标、按钮、链接、输入框、禁用控件、表格单元格、容器及弹窗内元素都可选择写说明，不限于预置 `data-anchor` 的区域。默认精确选中点击的元素，悬停时显示范围；支持用 ↑ 选外层、↓ 返回内层、Enter 确认。只拦截拾取过程的指针与点击事件，避免选中控件时触发业务。自动保存稳定位置，重绘、切页、重开和手动只读导出后仍能定位；动态列表按记录 ID 绑定，不因插入或排序指向其他记录。具体接入和验证见 [元素选择](element-targeting.md)。工作台导航、说明编辑器和编号覆盖层仍作为工具使用。
- **层级说明双数字**：隐藏弹窗或下一层的说明归到能打开它的业务按钮旁，不另加「弹窗说明」列表或横条。保留按钮自身的实心说明编号，旁边用空心数字显示内部有效说明的数量（数量不是新的说明 ID）；没有自身说明时只显示内部数量，不编造编号。点击实心编号只定位本按钮，点击内部数量打开下一层并高亮其中首条说明；更深层级在各自入口继续显示。内部数量以实际父子入口关系计算，不把任意隐藏页面或后台被遮挡的说明当作子层级。数字不能遮住业务点击，支持键盘，隐藏边框时仍可用；工作页和只读导出一致。
- **导出文件固定只读**：工作页右上角的导出按钮生成含全局描述、上线后数据需求、埋点说明及各产品全局说明正文、全部需求、产品与端的页面映射、数据、状态、已有全局文字和已保存说明的独立 HTML。导出文件保留「需求说明」下的三个文字入口、产品下的全局说明及页面二级菜单、归属和当前标识，可以切换目录、体验中间原型和定位说明，不能进入标注或修改说明，没有编辑/删除/重新导出入口；工作网页导出后仍可编辑。
- HTML 内联 CSS、JS、图标和必要资源，查看与只读交付不依赖外部程序。编辑版从同目录本地入口打开后自动写入工作 HTML；浏览器暂存仅作备份，交付内容以实际文件为准。


## 保存与导出


- 需求正文、各产品全局正文、已有全局文字和说明正文全部按纯文本渲染，保留换行，不执行 HTML 或解释 Markdown；JSON 内嵌时转义 `<`、`>`、`&`，避免正文或项目名截断 script 标签。
- 说明绑定稳定的需求 ID、页面 ID、状态、锚点和必要场景数据；页面 ID 在整个工作台内唯一，并映射到产品 ID 和端 ID。两个产品的同名页面、相同 DOM 锚点不能共用页面状态或说明。新增页面可使用带产品和端的命名空间；已有工作台补归属时保留原页面 ID、说明编号与缓存身份。新增记录和计数器必须一起导出，编号不回收。
- 导出从原始 HTML 外壳加当前完整模型生成，不直接保存运行后 DOM。未保存说明草稿或失效锚点必须提示处理后再导出。
- 手动保存可编辑副本使用 `readOnly: false`、新的快照键并保留完整说明草稿；该备份入口不套用只读导出的草稿阻断。
- 工作版默认交付已绑定文件的「打开工作台」编辑入口，填写后自动写入原 HTML。无连接、启用保存或文件选择器。顶部区分等待、正在保存、已自动保存与失败；版本变化时停止覆盖，当前编辑保留。离线页明确标注未落盘，不能作为默认编辑入口；关闭未落盘内容时提醒。具体写入、读回与多窗口处理见 [文件保存](storage.md)。
- 只读导出载荷写入 `readOnly: true`，启动时只开放查看与体验，并在写入入口检查只读；不能只通过 CSS 隐藏按钮。工作文件保持 `readOnly: false`。
- 查看文件使用独立缓存，重开时以文件内说明为准，不从旧缓存恢复说明或全局文字的修改及草稿。旧工作缓存缺少全局字段时补空字符串，不重置其他数据；独立保存工作台全局、产品全局及业务页的视图状态与滚动；产品正文按稳定产品 ID 保存，改显示名不改存储键。业务原型操作仍可演示，不能把所有表单和按钮一并禁用。


缓存与文件更新冲突的处理见 [存储与迭代](storage.md)。
